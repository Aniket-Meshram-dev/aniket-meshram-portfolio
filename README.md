## 🚀 Overview

A state-of-the-art interactive developer portfolio engineered with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**. Designed with micro-interactions, responsive bento grids, real-time GitHub integration, and tactile motion physics.

### ✨ Key Highlights

- **Hero Experience**: 
  - Traveling Hyper-Drive Neon Laser Beams with crisp optical bloom.
  - Staggered 3D typographic characters with magnetic spring-float physics on hover.
  - Periodic luxury metallic sheen sweeps.
  - Dual magnetic CTAs with organic breathing micro-glow and 1-click recruiter fast CV access.
  - Smooth-scrolling mouse chassis indicator.
- **Bento About Grid**:
  - Live orbital clock with analog ticking gear mechanics, planetary nodes, and time-zone telemetry.
  - Interactive tactile audio-visual soundboard with custom synthesizers and sound effects.
  - Tech stack orbital wheel and live status monitor.
- **Interactive Projects Showcase**:
  - Filterable by Full-Stack, AI / ML, and Web3 / Frontend.
  - Deep-dive project modals with interactive image galleries, architectural breakdowns, and live demo links.
- **GitHub Contribution Matrix**:
  - 365-day SVG calendar visualization mirroring actual GitHub commits and streak data.
  - Multi-year filter tabs, segmented streak cards, and direct repository links.
- **Holographic Certificate Modal**:
  - 3D perspective tilt on hover with dynamic holographic light reflection.
  - Direct PDF preview and verification links.
- **Global Command Palette (⌘K / Ctrl+K)**:
  - Instant spotlight search for quick navigation across sections, projects, and social links.
- **Tactile Performance**:
  - Lenis smooth scrolling integrated with RAF loop synchronization.
  - Magnetic cursor physics and GPU-accelerated micro-interactions.

## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm, pnpm, or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aniket-Meshram-dev/aniket-meshram-portfolio.git
   cd aniket-meshram-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the app.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
